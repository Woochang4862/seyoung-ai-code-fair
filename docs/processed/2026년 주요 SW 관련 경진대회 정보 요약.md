
# 2026년 주요 SW 관련 경진대회 정보 요약

요청하신 5개 주요 소프트웨어 관련 경진대회(한국정보올림피아드, 전국학생과학발명품경진대회, NYPC, 한국코드페어, SW사고력올림피아드)에 대한 2026년 기준 최신 정보를 정리하여 안내해 드립니다. 2026년 3월 16일 현재, 일부 대회의 2026년 공식 요강이 아직 발표되지 않은 경우가 있어, 해당 대회는 2025년 정보를 기준으로 예상 일정을 함께 안내합니다.

---

## 1. 한국정보올림피아드 (KOI)

한국정보올림피아드(KOI)는 과학기술정보통신부가 주최하고 한국정보과학회가 주관하는 국내 최고 권위의 알고리즘 프로그래밍 대회입니다. 초·중·고등학생을 대상으로 하며, 1차와 2차 대회를 통해 매년 국제정보올림피아드(IOI)에 참가할 국가대표를 선발합니다. [1]

**2026년 정보는 아직 공식 발표되지 않았습니다.** 아래는 2025년도 정보를 바탕으로 한 예상 내용입니다.

| 구분 | 내용 |
| --- | --- |
| **주최/주관** | 과학기술정보통신부 / 한국정보과학회 |
| **참가 대상** | 대한민국 국적을 가진 초·중·고등학생 또는 이에 준하는 청소년 |
| **예상 대회 일정 (2025년 기준)** | - **1차 대회 접수**: 2026년 4월 말 ~ 5월 중순
- **1차 대회**: 2026년 6월 초
- **2차 대회**: 2026년 7월 중순 |
| **신청 방법** | 공식 홈페이지([https://koi.or.kr](https://koi.or.kr))를 통한 온라인 접수 |
| **참가 조건** | - 초등부, 중등부, 고등부로 나누어 진행
- 응시료: 약 10만원 (2025년 기준) |
| **공식 정보** | [한국정보올림피아드 홈페이지](https://koi.or.kr) |


## 2. 전국학생과학발명품경진대회

전국학생과학발명품경진대회는 과학기술정보통신부가 주최하고 국립중앙과학관이 주관하는, 과학 발명을 통해 창의력과 탐구심을 함양하는 것을 목표로 하는 대회입니다. [2]

**2026년 제47회 대회 정보가 공식 발표되었습니다.**

| 구분 | 내용 |
| --- | --- |
| **주최/주관** | 과학기술정보통신부 / 국립중앙과학관, 동아일보 |
| **참가 대상** | 전국 초·중·고등학교 재학생 |
| **대회 일정 (전국대회)** | - **원서 접수**: 2026년 7월 1일(수)
- **1차 심사(서면)**: 2026년 7월 22일(수) ~ 7월 31일(금)
- **2차 심사(면담)**: 2026년 8월 11일(화)
- **결과 발표**: 2026년 8월 28일(금)
- **시상식**: 2026년 10월 7일(수) |
| **신청 방법** | 각 시·도 교육청에서 주관하는 본선대회를 거쳐 선발된 학생에 한해 전국대회 출품 자격 부여 |
| **참가 조건** | - 1인 1작품 원칙
- 지도교원 1인 필수 포함 |
| **공식 정보** | [국립중앙과학관 홈페이지](https://www.science.go.kr) |


## 3. NYPC (Nexon Youth Programming Challenge)

NYPC는 넥슨과 넥슨재단이 주최하는 청소년 대상 프로그래밍 챌린지입니다. 코딩에 대한 관심과 흥미를 높이고, 문제 해결 능력을 함양할 수 있는 재미있고 창의적인 문제들을 제공하는 것이 특징입니다. [3]

**2026년 정보는 아직 공식 발표되지 않았습니다.** 아래는 2025년도 정보를 바탕으로 한 예상 내용입니다.

| 구분 | 내용 |
| --- | --- |
| **주최/주관** | 넥슨, 넥슨재단 |
| **참가 대상** | 12세 ~ 19세 청소년 |
| **예상 대회 일정 (2025년 기준)** | - **참가 신청**: 2026년 7월 초 ~ 8월 초
- **온라인 예선 (Round 1, 2)**: 2026년 8월 중
- **본선 대회**: 2026년 10월 말 |
| **신청 방법** | 공식 홈페이지([https://nypc.co.kr](https://nypc.co.kr))를 통한 온라인 접수 |
| **참가 조건** | - 참가비 무료
- 넥슨 ID 필요 |
| **공식 정보** | [NYPC 홈페이지](https://www.nypc.co.kr) |


## 4. 한국코드페어 (Korea CodeFair)

한국코드페어는 과학기술정보통신부가 주최하고 한국지능정보사회진흥원(NIA)이 주관하는 청소년 대상 SW 행사입니다. SW공모전과 해커톤 두 부문으로 나뉘어 진행되며, 창의적인 아이디어를 SW로 구현하는 능력을 평가합니다. [4]

**2026년 정보는 아직 공식 발표되지 않았습니다.** 아래는 2025년도 정보를 바탕으로 한 예상 내용입니다.

| 구분 | 내용 |
| --- | --- |
| **주최/주관** | 과학기술정보통신부 / 한국지능정보사회진흥원 |
| **참가 대상** | 대한민국 국적의 초·중·고등학생 또는 이에 준하는 청소년 |
| **예상 대회 일정 (2025년 기준)** | - **SW공모전 접수**: 2026년 5월 말 ~ 6월 중순
- **해커톤 접수**: 2026년 7월 중순 ~ 8월 중순
- **본선 및 시상**: 2026년 10월 ~ 12월 |
| **신청 방법** | 공식 홈페이지([https://kcf.or.kr](https://kcf.or.kr))를 통한 온라인 접수 |
| **참가 조건** | - 개인 또는 3인 이하 팀으로 참가
- 참가비 무료 |
| **공식 정보** | [한국코드페어 홈페이지](https://kcf.or.kr) (현재 네이버 블로그로 운영) |


## 5. SW사고력올림피아드

SW사고력올림피아드는 전자신문사와 SW중심대학 등이 공동 주최하며, 청소년들의 컴퓨팅 사고력(Computational Thinking)과 문제 해결 능력을 평가하는 데 중점을 둔 대회입니다. [5]

**2026년 정보는 아직 공식 발표되지 않았습니다.** 아래는 2025년도(제11회) 정보를 바탕으로 한 예상 내용입니다.

| 구분 | 내용 |
| --- | --- |
| **주최/주관** | 전자신문사, 한국소프트웨어산업협회, 서울교육대학교 등 |
| **참가 대상** | 초등학교 3학년 ~ 중학교 3학년 |
| **예상 대회 일정 (2025년 기준)** | - **참가 신청**: 2026년 4월 ~ 5월 초
- **대회일**: 2026년 5월 말 |
| **신청 방법** | 접수 대행 사이트(예: 껌이지)를 통한 온라인 접수 |
| **참가 조건** | - 참가비 무료 (단, 보증금 제도를 운영할 수 있음)
- 전국 주요 도시 지정 고사장에서 오프라인으로 진행 |
| **공식 정보** | [이티에듀 홈페이지](https://www.etedu.co.kr) 또는 접수 사이트에서 확인 |
