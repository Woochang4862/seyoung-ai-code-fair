## 3. 수상 트렌드 분석

### 최상위 수상작 공통 패턴

1. **일상 불편 → 과학 원리로 해결**: 거창한 기술이 아닌, 누구나 겪는 불편함에서 출발
2. **수학/물리 원리의 명확한 적용**: 단순 아이디어가 아닌 원리 기반 설계 (사이펀, 코사인 함수 등)
3. **저비용 + 높은 실용성**: 바로 상품화 가능한 수준
4. **기존 제품과의 명확한 비교**: "기존 것은 이렇고, 내 것은 이렇다" 차별화
5. **전자장치 없이도 수상 가능**: 아두이노 없는 기구학적 발명도 최상위 수상

### 중3 학생의 전략적 포지션

- 중1이 상위권을 많이 차지 → 중3은 **"이 학년 수준에 맞는 과학적 깊이"**로 차별화
- 중3 수준의 물리·수학 개념(힘의 합성, 유체역학, 기하학 등)을 적극 활용해야 유리

## 4. 아이디어 제안

### 아이디어 1: 칠판 분필가루 하향 포집기 (추천 1순위)

**작품명 예시**: "기류 유도와 정전기 원리를 활용한 칠판 분필 분진 포집 장치 연구"

| 항목 | 내용 |
|------|------|
| 일상 불편 | 칠판 지울 때 분필가루가 교실에 비산 → 호흡기 건강 위협 |
| 과학 원리 | 코안다 효과(기류 유도) + 정전기 흡착 → 지우개 하단 부착형 포집부 |
| 차별점 | 기존 전동 지우개는 비싸고 무거움 → 전기 없이 물리적 포집 |
| 예상 비용 | 정전기 필름 + 기류 유도판 = 약 1만원 |
| 심사 강점 | 학교 현장 문제, 보건 이슈 연결, 분진량 측정 데이터 수집 용이(탐구일지 충실) |
| 창의·탐구성 | 코안다 효과라는 중3 수준 유체역학 원리 적용 → 학력 수준 적합성 높음 |
| 실용성 | 모든 학교 칠판에 적용 가능, 교사·학생 모두 수혜 |
| 경제성 | 기존 전동 지우개(5~10만원) 대비 1/5 이하 비용 |

#### 제작 방향
1. 칠판 지우개 하단에 기류 유도판(코안다 곡면) 부착
2. 분필가루가 아래로 유도되어 트레이에 포집
3. 정전기 필름으로 미세 분진 2차 포집
4. 포집 전/후 분진량 비교 실험 → 탐구일지 데이터

### 아이디어 2: 펌프 용기 잔량 제거 구조 (추천 2순위)

**작품명 예시**: "유체역학 원리를 활용한 액상 내용물 잔량 제거 펌프 용기 개발"

| 항목 | 내용 |
|------|------|
| 일상 불편 | 샴푸, 세제 등 펌프 용기 바닥에 남는 10~15% 내용물 |
| 과학 원리 | 모세관 현상 + 사이펀 원리 → 바닥 곡면 설계로 잔량을 중앙으로 집중 |
| 차별점 | 기존 해결법(뒤집기, 물 넣기)은 불편 → 용기 구조 자체로 해결 |
| 예상 비용 | 3D프린팅 시제품 1~2만원 |
| 심사 강점 | 45회 대통령상(사이펀 원리)과 유사한 접근, 환경 이슈(낭비 감소) 연결 |
| 창의·탐구성 | 유체역학 + 표면장력 실험 → 데이터 기반 설계 |
| 실용성 | 모든 가정에서 즉시 적용 가능 |
| 경제성 | 기존 펌프에 내부 구조물 추가만으로 해결 |

#### 제작 방향
1. 다양한 바닥 곡면 형상(원추, 포물면 등) 3D프린팅 시제품 제작
2. 잔량 비교 실험 → 최적 곡면 도출
3. 기존 펌프 용기와 잔량 비교 데이터 정리
4. 연간 가구당 낭비량 추산 → 경제성 어필

### 아이디어 3: 무소음 자동 복원 교실 의자 (추천 3순위)

**작품명 예시**: "댐퍼 기구와 탄성력을 이용한 무소음 자동 복원 교실 의자 개발"

| 항목 | 내용 |
|------|------|
| 일상 불편 | 교실 의자 끄는 소음, 뒤로 빠진 의자가 통로를 막음 |
| 과학 원리 | 로터리 댐퍼(점성 저항) + 토션 스프링 → 일어나면 천천히 원위치 |
| 차별점 | 기존 의자 다리 패드는 소음만 줄임 → 이 발명은 자동 복원까지 |
| 예상 비용 | 로터리 댐퍼 + 토션 스프링 = 약 1~2만원 |
| 심사 강점 | 학교생활 기반, 중3 수준 역학(토크, 점성 저항) 이해 어필 |
| 창의·탐구성 | 댐핑 계수 조절 실험 → 최적 복원 속도 도출 |
| 실용성 | 기존 의자에 부착하는 방식으로 교체 비용 없음 |
| 경제성 | 의자 전체 교체(5~10만원) 대비 부착 키트(1~2만원) |

#### 제작 방향
1. 의자 다리에 부착하는 레일 + 복원 기구 설계
2. 댐퍼 강도별 복원 속도/소음 비교 실험
3. 소음 측정(dB) 전후 비교 데이터
4. 교실 환경에서 실제 사용 테스트

### 아이디어 4: 한 손으로 여닫는 우유팩 클립

**작품명 예시**: "지렛대 원리와 식품안전 소재를 활용한 우유팩 원핸드 밀봉 클립 개발"

| 항목 | 내용 |
|------|------|
| 일상 불편 | 급식 우유팩 개봉 후 다 못 마시면 쏟아짐, 밀봉 불가 |
| 과학 원리 | 지렛대 원리(적은 힘으로 강한 밀봉) + 탄성 변형 |
| 차별점 | 기존 클립은 범용 → 우유팩 규격에 최적화된 전용 설계 |
| 예상 비용 | 식품안전 플라스틱 3D프린팅 = 약 5천원 |
| 심사 강점 | 46회 국무총리상(휴지갑)과 같은 "일상 소품 혁신" 노선 |

### 아이디어 5: 자전거 후방 사각지대 촉각 경고장치

**작품명 예시**: "초음파 센서 기반 자전거 후방 사각지대 접근 촉각 경고 장치 연구"

| 항목 | 내용 |
|------|------|
| 일상 불편 | 이어폰 착용 중학생 자전거 사고 증가 |
| 과학 원리 | 초음파 반사 원리 → 거리별 진동 강도를 달리하여 핸들에 전달 |
| 차별점 | 기존 후방 경고장치는 소리/빛 기반 → 이어폰 환경에서 무용, 촉각 방식은 없음 |
| 예상 비용 | 아두이노 나노 + 초음파센서 3개 + 진동모터 = 약 2~3만원 |
| 심사 강점 | 중학생 실생활 밀착, 안전 이슈, 독창성 높음 |

---

## 5. 최종 추천 순위

| 순위 | 아이디어 | 추천 이유 |
|------|---------|----------|
| 1 | 칠판 분필가루 포집기 | 학교 현장+보건 이슈, 실험 데이터 수집 용이, 독창성 높음, 전자장치 불필요 |
| 2 | 펌프 용기 잔량 제거 | 45회 대통령상과 같은 노선(유체역학), 실용성 극대화, 환경 이슈 연결 |
| 3 | 무소음 자동복원 의자 | 역학 원리 깊이 있게 활용, 중3 수준 어필, 학교생활 기반 |
| 4 | 우유팩 밀봉 클립 | 46회 국무총리상 노선, 최저 비용, 제작 난이도 낮음 |
| 5 | 자전거 촉각 경고장치 | 독창성 최고, 다만 아두이노 코딩 경험 필요 |
