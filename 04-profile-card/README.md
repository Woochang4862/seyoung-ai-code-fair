# 04. Profile Card

**회차**: 12회차 (2026.04.12) — 메인 프로젝트

## 목표
- 지금까지 배운 위젯들을 조합해서 완성된 화면 만들기
- 자기만의 디자인으로 커스터마이징하기

## 구현할 화면
```
┌─────────────────────────┐
│      (프로필 아이콘)     │
│                         │
│         김민성          │
│     길음중학교 3학년     │
│                         │
│     ⭐ 꿈: 개발자 ⭐    │
│                         │
│   [ 좋아요 ] [ 메시지 ]  │
└─────────────────────────┘
```

## 사용한 위젯
- Container (카드 외곽 + 그림자)
- Column / Row (레이아웃)
- Icon, Text (콘텐츠)
- SizedBox (간격)
- ElevatedButton (버튼)

## 🎯 도전 과제
1. 프로필 아이콘을 실제 이미지(`Image.network`)로 교체
2. 배경색/폰트/아이콘을 자기 스타일로 **3군데 이상** 변경
3. Flutter 공식 문서에서 새 위젯 1개 찾아 추가

## 📂 Git 브랜치 구조

이 프로젝트는 **로컬 Git**으로 버전 관리되어 있습니다.

| 브랜치 | 내용 |
|--------|------|
| `main` | 시작 코드 + 도전 과제 TODO 주석 |
| `solution` | 도전 과제 3개 모두 구현된 완성본 |

### 🔍 정답 확인 방법
**먼저 충분히 시도한 뒤** 정답이 궁금하면:
```bash
git checkout solution    # 정답 보기
git checkout main        # 다시 시작 코드로
```

### 현재 브랜치 확인
```bash
git branch
# * main        ← 지금 이 브랜치
#   solution
```
