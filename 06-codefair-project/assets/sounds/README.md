# 경고음 파일

이 폴더에 `alert.mp3` 파일을 넣으면 졸음 감지 시 자동으로 재생됩니다.

## 추천 사이트

- https://pixabay.com/sound-effects/search/alarm/ (저작권 무료)
- https://freesound.org/

## 설치 방법

1. 위 사이트에서 짧은(1~2초) 경고음 mp3 다운로드
2. 파일 이름을 `alert.mp3`로 변경
3. 이 폴더(`assets/sounds/`)에 저장
4. `flutter pub get` 실행

파일이 없어도 앱은 동작하며, 단지 경고음만 안 울립니다.
