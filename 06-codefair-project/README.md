# 06. 한국코드페어 프로젝트

**접수 마감**: 2026.05.25

## 프로젝트 개요
**버스 운전기사 위험상황 인지 대응 시스템**
카메라 + AI(티쳐블 머신) 기반으로 운전기사의 졸음/위험 상황을 감지하는 앱

## 기술 스택
- **AI**: Teachable Machine (눈 감기 감지 모델)
- **언어/프레임워크**: Python (AI 모델 연동), Flutter (모바일 앱 UI)
- **플랫폼**: Android/iOS

## 개발 일정 (약 6주)
| 주차 | 목표 |
|------|------|
| 1~2 | Flutter 기초 (프로필 카드, StatefulWidget) |
| 3 | 카메라 화면 구현, 기본 UI 구성 |
| 4 | AI 모델 연동 (눈 감기 감지) |
| 5 | 알림/경고 기능, UX 개선 |
| 6 | 테스트, 발표 자료 준비, 제출 |
